# ÉQUI-ÉDUC BF – Observatoire des disparités d'accès à l'éducation

Data Challenge Burkina 2026 · Défi 2 (parité fille-garçon, écart urbain-rural) · Équipe EquiData BF.

**Application en ligne : https://pertiew.github.io/equidata-bf-tableau-de-bord/**

Application autonome (un seul fichier `index.html`, sans serveur ni appel réseau) : quatre onglets en langage simple : **L'essentiel**, **Où agir** (carte, priorités, fiche imprimable par province, profils et actions), **Tendances** (2015-2025) et **Comment c'est calculé**. Code couleur unique (vert = bon, ocre = à surveiller, rouge = préoccupant), recherche par province ou région, visite guidée au premier lancement.

Données agrégées issues de sources publiques : DGESS/MEBAPLN (statistiques préscolaire et primaire, annuaires du primaire), INSD (RGPH 2019, projections, EHCVM, profils de pauvreté), EDS 2021, SP/CONASUR, COD-AB (IGB/OCHA).

Les versions précédentes sont conservées dans `archives/` (`tableau_de_bord_v1.html`, `tableau_de_bord_v2_6onglets.html`).
